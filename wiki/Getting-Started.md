# Первоначальная настройка

Эта страница проведёт вас от первого входа до первой автоматически скачанной раздачи.
Предполагается, что TorrentMonitor уже установлен —
[в Docker](Installation-Docker) или [в LAMP](Installation-LAMP).

---

## Шаг 1 — Первый вход и смена пароля

Откройте адрес TorrentMonitor в браузере. Пароль по умолчанию:

```
torrentmonitor
```

Сразу смените его: **Настройки → Смена пароля**. Там же, на вкладке «Основные»,
убедитесь, что включён тумблер «Включить вход по паролю» — особенно если интерфейс
доступен не только из локальной сети.

## Шаг 2 — Базовые настройки

В **Настройки → Основные** заполните:

- **Адрес TM** — полный адрес вашего TorrentMonitor с протоколом,
  например `http://192.168.1.10:8080/`. Используется в уведомлениях и RSS-ленте.
- **User-Agent** — можно оставить предложенный; трекеры видят его при запросах.

Подробно про все настройки — на странице [Настройки](Settings).

## Шаг 3 — Учётные данные трекеров

Большинство трекеров отдают `.torrent`-файлы только авторизованным пользователям,
поэтому TorrentMonitor должен заходить на трекер под вашей учётной записью.

Откройте раздел **Учётные данные**, выберите трекер и укажите логин и пароль от него.
Заполняйте только те трекеры, которыми пользуетесь. Особенности отдельных трекеров
(зеркала, качество, RSS) описаны в [списке трекеров](Supported-Trackers).

Проверить, что авторизация работает, можно в разделе **Тестирование**.

## Шаг 4 — Подключить торрент-клиент (по желанию)

TorrentMonitor умеет сам добавлять и заменять раздачи в клиенте:
Transmission, qBittorrent, Deluge, TorrServer или Synology Download Station.

**Настройки → Торрент-клиент** → включите «Управлять торрент-клиентом», выберите клиент,
укажите его адрес, логин/пароль и директорию для скачивания.
Подробности по каждому клиенту — на странице [Торрент-клиенты](Torrent-Clients).

Если клиент не подключать, TorrentMonitor будет просто складывать свежие
`.torrent`-файлы в каталог `torrents/` — их можно забирать оттуда любым способом.

## Шаг 5 — Добавить первую раздачу

Нажмите кнопку **Добавить**. Есть три варианта:

### Тему (форумные трекеры: rutracker, kinozal, nnmclub и др.)

- **Ссылка на тему** — адрес страницы раздачи,
  например `http://rutracker.org/forum/viewtopic.php?t=4201572`.
- **Название** — необязательно, подтянется само (тумблер «Обновлять заголовок автоматически»).
- **Директория для скачивания** — необязательно; если пусто, используется директория
  из настроек торрент-клиента (у qBittorrent — папка по умолчанию или папка категории).
- **Категория qBittorrent** — необязательно, только при клиенте qBittorrent.

Когда в теме обновят торрент (например, добавят новую серию), TorrentMonitor скачает
новый `.torrent`, удалит из клиента старую раздачу и добавит новую.

### Сериал (RSS-трекеры: lostfilm.tv, newstudio.tv, baibako.tv, hamsterstudio.org)

Выберите трекер, введите **название сериала на английском** (например `House`)
и качество (SD / 720p / 1080p). TorrentMonitor будет ловить новые серии в ленте трекера.

### Пользователя

Мониторинг всех новых раздач конкретного релизёра на трекере —
удобно следить за любимой релиз-группой. Новые темы появляются в разделе «Пользователи».

## Шаг 6 — Проверить работу

- Раздел **Запуск** — запускает проверку вручную, не дожидаясь расписания
  (в Docker проверка выполняется по cron автоматически, по умолчанию раз в час;
  в LAMP — по заданному вами crontab).
- Раздел **Ошибки** — если что-то пошло не так (неверный пароль трекера, трекер недоступен),
  здесь появится предупреждение.
- Раздел **Торренты** — список отслеживаемых раздач и их статус.
