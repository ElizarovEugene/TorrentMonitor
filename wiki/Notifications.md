# Уведомления

TorrentMonitor отправляет уведомления двух типов:

- **об обновлениях** — вышла новая серия, обновилась раздача;
- **об ошибках** — не удалось войти на трекер, трекер недоступен и т.п.

Для каждого типа можно выбрать свой сервис и адрес.

## Включение

1. **Настройки → Основные** → включите «Включить уведомления».
2. Появится вкладка **Уведомления**: включите нужные типы, выберите сервис
   и заполните поле «Адрес» в формате из таблицы ниже.

## Сервисы и формат поля «Адрес»

| Сервис | Формат поля «Адрес» | Где взять |
|---|---|---|
| **E-mail** | адрес почты, например `user@example.com` | отправка через PHP `mail()` — на сервере должен работать sendmail/MTA |
| **Telegram** | `ТОКЕН_БОТА;CHAT_ID` — можно несколько получателей: `ТОКЕН;CHAT_ID1;CHAT_ID2` | токен — у [@BotFather](https://t.me/BotFather); chat_id — например, у @userinfobot; бота нужно добавить в чат |
| **Pushover** | `USER_KEY;APP_TOKEN` | [pushover.net](https://pushover.net/) |
| **Pushbullet** | Access Token | [pushbullet.com → Settings → Access Tokens](https://www.pushbullet.com/#settings/account) |
| **Prowl** | API key | [prowlapp.com](https://www.prowlapp.com/) (iOS) |
| **PushAll** | `ID;KEY` | [pushall.ru](https://pushall.ru/) |

### Telegram: отправка в тему (тред) супергруппы

Если чат — супергруппа с темами, укажите ID темы через двоеточие после chat_id:

```
ТОКЕН_БОТА;-1001234567890:42
```

где `42` — `message_thread_id` нужной темы. Форматы можно совмещать:
`ТОКЕН;CHAT_ID1;CHAT_ID2:THREAD_ID`.

## Проверка

Самый простой способ проверить уведомления — добавить активно обновляющуюся раздачу
и запустить проверку в разделе **Запуск**, либо временно указать неверный пароль
трекера и убедиться, что пришло уведомление об ошибке (не забудьте вернуть пароль).

## Если уведомления не приходят

- **E-mail**: убедитесь, что PHP умеет отправлять почту (`mail()` требует настроенный
  sendmail; в Docker-контейнере его нет — используйте Telegram или push-сервисы).
- **Telegram**: бот должен быть добавлен в чат и не заблокирован; для группы chat_id
  отрицательный (начинается с `-100…`).
- Проверьте, включены ли оба тумблера: глобальный («Включить уведомления»)
  и конкретного типа («Отправлять уведомления об обновлениях/ошибках»).
- Если TM ходит в интернет через прокси, уведомления тоже идут через него —
  проверьте доступность api.telegram.org и других сервисов.
