# Интеграция с Sonarr

TorrentMonitor интегрируется с [Sonarr](https://sonarr.tv/):
Sonarr находит и берёт релиз, а TorrentMonitor автоматически ставит соответствующую
тему трекера на мониторинг и дальше сам скачивает обновления раздачи.

## Как это работает

1. Sonarr находит подходящий релиз и отдаёт его в **qBittorrent**.
2. qBittorrent получает `.torrent` и начинает скачивание.
3. Одновременно Sonarr отправляет **On Grab**-уведомление в TorrentMonitor
   (webhook `POST /api/sonarr`).
4. TM берёт `downloadId` (хеш торрента) из запроса Sonarr и запрашивает у qBittorrent
   поле **comment** этого торрента — там должна быть ссылка на тему форума-трекера
   (например, rutracker.org кладёт её туда всегда).
5. По этой ссылке TM добавляет тему на мониторинг и будет автоматически скачивать
   обновления раздачи (новые серии).

Таким образом Sonarr отвечает за выбор релиза, а TorrentMonitor — за его
дальнейшее сопровождение.

## Требования

- TorrentMonitor настроен и работает.
- В настройках TM выбран торрент-клиент **qBittorrent** с корректным адресом и паролем
  (см. [Торрент-клиенты](Torrent-Clients#qbittorrent)). Сейчас интеграция работает
  только с qBittorrent: ссылку на тему TM читает из поля comment торрента через его API.
- Sonarr использует **тот же qBittorrent** в качестве Download Client.
- В TM заполнены **Учётные данные** для трекера, с которого скачивается торрент.
- Трекер должен быть форумным и поддерживаемым TM (rutracker.org, kinozal, nnmclub.to
  и др. — см. [список](Supported-Trackers)); ссылка на тему должна присутствовать
  в поле comment торрента.

## Шаг 1 — Сгенерировать API-ключ в TorrentMonitor

1. Откройте **Настройки → API**.
2. Нажмите **Сгенерировать ключ** и скопируйте его.

## Шаг 2 — Добавить Webhook в Sonarr

1. Откройте **Settings → Connect → + (Add Connection) → Webhook**.
2. Заполните:

   | Поле | Значение |
   |---|---|
   | Name | `TorrentMonitor` |
   | Notification Triggers | **On Grab** (только это) |
   | URL | `http(s)://ВАШ_АДРЕС_ТМ/api/sonarr?token=ВАШ_КЛЮЧ` |
   | Method | `POST` |

3. Нажмите **Test** — должен появиться ответ `{"ok":true,"message":"OK"}`.
4. Сохраните.

> 💡 Если Sonarr работает через прокси (**Settings → General → Proxy**), webhook тоже
> пойдёт через него и до локального адреса TM не дойдёт. Добавьте адрес TM в поле
> **Ignored Addresses** настроек прокси Sonarr. Флажка «Bypass Proxy for Local Addresses»
> недостаточно: локальными Sonarr считает только адреса без точки в имени
> и `localhost`/`127.0.0.1`, а `192.168.…` под это не подпадает.

## Категория qBittorrent (по желанию)

Чтобы раздачи, добавленные через Sonarr, получали отдельную категорию в qBittorrent,
добавьте параметр `category` в URL webhook:

```
http://ВАШ_АДРЕС_ТМ/api/sonarr?token=ВАШ_КЛЮЧ&category=sonarr
```

Если параметр не указан, применяется «Категория по умолчанию» из
**Настройки → Торрент-клиент** (см. [Настройки](Settings#вкладка-торрент-клиент)).

## Проверка

Возьмите в Sonarr любой релиз (Interactive Search → Grab) с трекера, для которого
в TM заполнены учётные данные. Через несколько секунд тема должна появиться
в разделе **Торренты** TorrentMonitor, а при включённых [уведомлениях](Notifications)
придёт сообщение «Тема … добавлена на мониторинг через Sonarr».

## Возможные проблемы

Ошибки интеграции отображаются в разделе **Ошибки** TM, а webhook возвращает их текстом:

| Сообщение | Причина и решение |
|---|---|
| `Неверный токен` | ключ в URL не совпадает с ключом в TM — перегенерируйте и обновите URL |
| `Нет downloadId в запросе` | Sonarr отправил событие без хеша торрента (обычно не On Grab — проверьте триггеры) |
| `Не удалось получить данные из qBittorrent` | TM не может подключиться к qBittorrent или торрента с таким хешем там нет; проверьте, что TM и Sonarr используют один и тот же qBittorrent |
| `comment торрента не содержит корректного URL форумной темы` | трекер не кладёт ссылку на тему в comment или трекер не поддерживается (RSS-трекеры lostfilm/newstudio не подходят) |
| `Нет учётных данных для трекера: …` | заполните этот трекер в разделе **Учётные данные** |
| `Тема уже отслеживается` | не ошибка: тема уже есть в мониторинге |
| Test в Sonarr падает с ошибкой соединения | TM недоступен по указанному URL. Если Sonarr работает через прокси — webhook уходит через него; добавьте адрес TM в **Ignored Addresses** (см. примечание к шагу 2) |
