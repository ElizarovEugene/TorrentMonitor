# Обновление

Трекеры регулярно меняют вёрстку и домены, поэтому обновляться стоит своевременно —
исправления модулей трекеров выходят с каждой версией
(см. [changelog](https://github.com/ElizarovEugene/TorrentMonitor/blob/master/changelog.txt)).

---

## Резервное копирование

Перед любым обновлением сохраните базу данных — в ней все раздачи, учётные данные
и настройки:

- **SQLite** — скопируйте файл базы (в Docker — содержимое тома `/data/htdocs/db`);
- **MySQL** — `mysqldump torrentmonitor > tm-backup.sql`;
- **PostgreSQL** — `pg_dump torrentmonitor > tm-backup.sql`.

## Обновление в Docker

Обновите образ и пересоздайте контейнер (`docker compose pull && docker compose up -d`
или средствами вашего NAS). Данные сохраняются в томах — при правильно настроенных
томах обновление безопасно. Подробная инструкция — в вики Docker-проекта:
[Updating-and-Maintenance](https://github.com/alfonder/torrentmonitor-dockerized/wiki/Updating-and-Maintenance).

## Автоматическое обновление (LAMP)

В **Настройки → Основные** есть тумблер «Автоматическое обновление TM» —
TorrentMonitor сам скачивает и устанавливает новые версии.
Для этого пользователь веб-сервера должен иметь права на запись во все файлы
приложения.

> В Docker этот механизм не используется — версия приложения фиксируется образом,
> обновляйтесь через `docker pull`.

## Ручное обновление (LAMP)

1. Сделайте резервную копию базы и `config.php`.
2. Скачайте новую версию и распакуйте поверх старой
   (или в новый каталог, перенеся `config.php`, `config.xml` и каталог `torrents/`).
3. Проверьте права: `chown -R www-data:www-data /var/www/torrentmonitor`.
4. Откройте веб-интерфейс — при необходимости TM обновит схему базы сам.

## Обновление базы данных

Изменения схемы базы применяются автоматически — патчи из `db_schema/patches/`
накатываются при первом запуске новой версии. Ничего вручную делать не нужно,
но **бэкап перед обновлением обязателен**: автоматического отката схемы нет,
вернуться на старую версию можно только восстановлением из копии.

## Откат

- **Docker**: укажите предыдущий тег образа (`alfonder/torrentmonitor:vX.X.X-N`)
  и восстановите базу из бэкапа, если схема успела обновиться.
- **LAMP**: разверните предыдущую версию файлов и восстановите базу из бэкапа.
